# Idéer till nya guider

Den dagliga rutinen (`docs/daglig-rutin.md`) tar den första punkten som inte är avbockad. Bocka av med
`[x]` och skriv guidens slug efter när den är publicerad. Lägg gärna till nya idéer längst ner – helst
sådant villaägare faktiskt söker på.

## Att skriva

- [ ] Luft-luft-värmepump på vintern: rätt inställningar för lägst elräkning
- [ ] Välj laddbox till elbilen: lastbalansering, appar och smart laddning
- [ ] Ladda elbilen smart utan Tibber: laddboxens egna appar och elprisstyrning
- [ ] Lastbalansering och effektvakt: så slipper du byta till större huvudsäkring
- [ ] Kan du sänka huvudsäkringen? Så ser du om det lönar sig
- [ ] Home Assistant för elstyrning: kom igång med elpris och smarta prylar
- [ ] Zigbee, Z-Wave, Thread och Matter: vilket smart hem-system ska du välja?
- [ ] Shelly: styr apparater efter elpriset utan Home Assistant
- [ ] Motorvärmare: styr den smart och spara el
- [ ] Gammal frysbox eller kyl – lönar det sig att byta?
- [ ] Standby-förbrukning: så mycket drar apparaterna när de är avstängda
- [ ] Torktumlare: värmepumpstorktumlare jämfört med kondens

- [ ] Fast eller rörligt elpris – vilket passar en villa?
- [ ] Energideklaration: vad den säger om ditt hus och vad du kan göra
- [ ] Tilläggsisolera vinden: när lönar det sig?

- [ ] Stödtjänster och flexibilitet: så kan hushåll få betalt för att hjälpa elnätet
